07 PadWidget Trigger Pads¶

PadWidget is an MPC-style grid of velocity-sensitive trigger pads. Each pad sends a MIDI note through the session bus; connect it to a sampler and you have a drum machine in a notebook cell.

  • Velocity-sensitive: click near the top of a pad for soft hits and near the bottom for hard hits.

  • Assignable notes: double-click a pad’s label to type a new note name (C#4) or MIDI number; scroll to nudge it a semitone.

  • Session routing: uses the same sampler_routing as KeyboardWidget, so one sampler can serve both.

from nbplay import PadWidget

# Create a 4×4 pad grid; the default notes are MIDI 36–51 (C2–D#3)
pads = PadWidget(rows=4, cols=4)
pads

Click any pad to hear a sine tone. The pad flashes on impact.

  • Velocity-sensitive by default: click near the top for a quiet hit (about velocity 20) and near the bottom for a loud one (up to the slider value).

  • Hold pads: several pads can be held at once for chords or layered hits.

  • Scroll wheel on a pad adjusts its note ±1 semitone.

  • Double-click a pad’s note label to type a new note name.

Custom Layout¶

Any rectangular grid works. Here is a 2×8 layout with a minor pentatonic scale mapped across the pads.

# 2 rows × 8 columns with a minor pentatonic scale starting at C2
pentatonic = [36, 38, 40, 43, 45, 48, 50, 52,
              55, 57, 60, 62, 64, 67, 69, 72]

pads_custom = PadWidget(
    rows=2,
    cols=8,
    pad_notes=pentatonic,
    velocity=80,
)

Pads + Sampler via Session¶

Connect the pads to a sampler through the session bus, the same way KeyboardWidget and MidiKeyboardWidget do.

import math
from nbplay import SamplerWidget, PadWidget

# Create a simple sine-wave "sample" for the sampler to play
sample_rate = 44100
duration = 0.5
freq = 440.0
frames = int(sample_rate * duration)
samples = [math.sin(2 * math.pi * freq * i / sample_rate) * 0.6 for i in range(frames)]

sampler = SamplerWidget(
    channel_index=0,
    root_note=60,
    attack=0.001,
    decay=0.05,
    sustain=0.8,
    release=0.1,
    max_voices=8,
)
sampler.load_sample(samples, sample_rate=sample_rate, root_note=60, name="Sine")

# 4×4 drum-style pads connected to the sampler
pads = PadWidget(rows=4, cols=4, velocity=110)
pads.connect_sampler(sampler)

What’s Next¶

  • Double-click any pad label to change its note; type C#4 or 60.

  • Scroll on a pad to nudge its note up or down one semitone.

  • Drag the velocity slider to set the maximum velocity; with Vel-Sensitive checked, click position within the pad determines actual velocity (top = soft, bottom = hard).

  • Combine PadWidget, KeyboardWidget, and SequencerWidget in one Session for a multi-instrument setup.
