10 MixerWidget Tutorial¶

Create channel strips, add built-in Web Audio insert effects, and register one notebook-local browser plugin hook.

from IPython.display import Javascript, display

from nbplay import EffectPlugin, MixerWidget

# Custom plugin hook. Built-in names remain reserved; use your own descriptor type.
display(Javascript(r"""
globalThis.__nbplayPlugins = globalThis.__nbplayPlugins || {};
globalThis.__nbplayPlugins.notebook_lowpass = (ctx, effect) => {
  const filter = ctx.createBiquadFilter();
  filter.type = "lowpass";
  filter.frequency.value = Number(effect.frequency ?? 1200);
  filter.Q.value = Number(effect.q ?? 0.7);
  return filter;
};
"""))

mixer = MixerWidget()
lead = mixer.add_channel("Lead")
bass = mixer.add_channel("Bass")
drums = mixer.add_channel("Drums")

mixer.set_channel_gain(lead, 0.78)
mixer.set_channel_pan(lead, 0.2)
mixer.add_channel_effect(lead, EffectPlugin("filter", filter_type="lowpass", frequency=3200, q=0.8))
mixer.add_channel_effect(lead, {"type": "notebook_lowpass", "frequency": 1800, "q": 0.9})

mixer.set_channel_gain(bass, 0.9)
mixer.set_channel_pan(bass, -0.15)
mixer.add_channel_effect(bass, EffectPlugin("compressor", threshold=-20, ratio=5, attack=0.004, release=0.18))

mixer.set_channel_gain(drums, 0.58)
mixer.add_channel_effect(drums, EffectPlugin("delay", time=0.18, feedback=0.22, wet=0.18))
mixer.add_channel_effect(drums, EffectPlugin("reverb", seconds=1.2, decay=2.4, wet=0.16))

mixer.master_gain = 0.84
mixer.add_master_effect(EffectPlugin("limiter", threshold=-1, release=0.05))

mixer

Try this after the mixer renders: change faders, toggle mute/solo, add effects from the widget controls, or run another cell that mutates mixer.channels and mixer.master_effects.

Send and Return Buses¶

A return bus is a shared effect chain with its own fader that feeds the master. Every channel gets a post-fader send level for it, so one reverb can serve several channels at different amounts. In the widget, + Return adds a bus, the small sliders on each channel strip set the sends, and the return strip edits its effects like any other strip.

verb = mixer.add_return("Verb", effects=[EffectPlugin("reverb", seconds=2.2, decay=3.0, wet=1.0)], gain=0.7)
mixer.set_send(lead, verb, 0.35)
mixer.set_send(drums, verb, 0.2)
print(mixer.returns[0]["name"], [channel["sends"] for channel in mixer.channels])
