nbplay.app¶

Serve a Session as a web page with every instrument in a resizable panel.

The widgets are the same objects a notebook displays: each hosts its models in its own transports session, which the app serves over one WebSocket per instrument, and the page binds each element to those models under the panel’s namespace. The panels are a regular-layout split/tab tree that the browser can rearrange.

python -m nbplay.app serves a demo session on http://127.0.0.1:8020.

The same page also runs with no server: Standalone is the Python side for a Pyodide Web Worker, with postMessage in place of the WebSockets (js/examples/pyodide.html, built by make pyodide-example).

nbplay.app.build(session, *, layout=None, title='nbplay', probes=False, **options)¶

A Starlette app serving session: one WebSocket per instrument and a panel layout page.

The page is a top bar (title and a theme select) over the panels. layout is a regular-layout split/tab tree over the panel names from panel_widgets(); probes adds the JSON routes the browser tests drive. Other keyword options go to spaday.backends.starlette.serve().

class nbplay.app.Standalone(session, *, layout=None, title='nbplay')¶

The Python side of the page with no server: what a Pyodide Web Worker runs.

Each panel’s transports server talks to one in-browser connection; the worker passes wire frames between this object and the page with postMessage. Every method takes and returns JSON text, the form that crosses the worker boundary.
