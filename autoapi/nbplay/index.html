class nbplay.MidiLearn(source)[source]¶

Route MIDI control changes to widget traits.

Parameters:

source – A widget with a synced control_change trait (MidiKeyboardWidget).

map() binds a controller number now; learn() binds the next controller the hardware sends, so you can call it and turn the knob. Bool traits switch on at values of 64 and above. Numeric traits scale the 0-127 value into [low, high], which default to 0-1 for floats and 0-127 for ints.
