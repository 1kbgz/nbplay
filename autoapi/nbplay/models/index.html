nbplay.models¶

Pydantic models behind the transports-backed views (nbplay.views).

Each widget splits into a config model the kernel owns and validates, and a status model the browser owns (hosted with owner="client"), matching the nbplay-set / nbplay-status split of the elements.

Classes¶

Transport state the browser clock owns.

The Web MIDI keyboard's port, clock following and routing.

Ports, held notes, control changes and the device clock; browser-owned.
