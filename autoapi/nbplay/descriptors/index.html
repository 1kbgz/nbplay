nbplay.descriptors¶

Validated descriptors and normalizers shared by the widgets and their models.

The widgets in nbplay.widget and the pydantic models in nbplay.models accept the same dict shapes for effects, mixer channels, timeline tracks and clips, pad actions, sampler zones and slices, launcher slots and keyboard routes. The descriptor classes (EffectPlugin, AudioClip, TimelineTrack, PadAction, KeyboardRoute) are the notebook-facing way to build them, and the _normalize_* functions are what both layers run on assignment.

class nbplay.descriptors.KeyboardRoute(channel_index: int, *, match: str = 'all', zone: str | None = None, octave: int | None = None, note: int | None = None, notes: list[int] | None = None)[source]¶

Validated route descriptor for keyboard → sampler mapping.

Determines which MIDI notes a KeyboardWidget or MidiKeyboardWidget routes to a specific sampler.

Parameters:

  • channel_index – The sampler’s channel index on the session bus (≥ 0).

  • match – One of "all", "zone", "octave", "note", "notes".

  • zone – Required when match=”zone”. "upper" or "lower".

  • octave – Required when match=”octave”. MIDI octave 0–9.

  • note – Required when match=”note”. Single MIDI note 0–127.

  • notes – Required when match=”notes”. Non-empty list of MIDI notes 0–127.
