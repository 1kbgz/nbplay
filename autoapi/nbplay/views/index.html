nbplay.views¶

Views: nbplay instruments on transports models, rendered by spaday.

A view hosts a config model (kernel-owned, validated) and a status model (browser-owned) in a transports.Session, and renders the instrument element with spaday bindings: config fields bind two-way on nbplay-set, status fields two-way on nbplay-status, and an nbplay-wire child delivers session.command calls to the element. This is the parallel layer to the traitlets widgets in nbplay.widget; it needs spaday[widget] with notebook session support and transports 0.12.
